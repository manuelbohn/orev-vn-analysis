## oREV-VN: An extension of the oREV vocabulary test with Rasch-compliant verb comprehension items

------------------------------------------------------------------------

> Data and analysis scripts associated with the following paper

------------------------------------------------------------------------

* Bohn, M., Carraro, C., Rykova, E., Prein, J. & Gagarina, N. (2026). [oREV-VN: An extension of the oREV vocabulary test with Rasch-compliant verb comprehension items](https://osf.io/preprints/psyarxiv/jn9wt_v1). *PsyArXiv*.

### Usage

Link to task (in German): [oREV-VN](https://devpsy.web.leuphana.de/orev-vn/)

### Structure

```
.
├── analysis                    <-- data analysis including item selection
├── data                        <-- data files
├── visuals                     <-- figures in paper
├── paper                       <-- reproducible manuscript file
└── saves                       <-- saved model outputs

```
